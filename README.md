## About

A RESTful social media backend built with Python and FastAPI
as a learning project to understand backend API development.

## What I Learned

- FastAPI
- REST API design
- CRUD operations
- Pydantic validation
- PostgreSQL
- SQLAlchemy
- Authentication & authorization
- JWT
- Password hashing
- API testing
- Docker
- API documentation with Swagger/OpenAPI

## Learning Source

Built while following the FastAPI API Development course
by freeCodeCamp.

The project was implemented locally while learning the concepts,
with additional modifications made during development.
